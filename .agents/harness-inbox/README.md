# Harness inbox

Drop external harness content here (skills, rules, docs). **Contents are gitignored** — only this README is tracked.

## How to use

1. Copy files or folders into this directory.
2. Add a one-line **origin** below (source URL, vendor, or chat name).
3. Run `/update-harness` in chat.
4. Review the disposition report under `documentation/jobs/harness/`.
5. Confirm apply → inbox cleared after successful ingest.
